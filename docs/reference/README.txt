Rinko Delivery Premium Contract Integration

Files included:
1. terms.html
   - Full premium Delivery Service Agreement page.
   - Upload this file to the same folder as your index.html.

2. terms-style.css
   - Styling for terms.html.
   - Keep it in the same folder as terms.html.

3. form-integration-snippet.html
   - Copy this block inside your existing quote/booking form before the submit button.

4. form-style-snippet.css
   - Copy this CSS into your main CSS file.

5. body-camera-notice.html
   - Optional notice for your booking page or FAQ.

Important Washington note:
Washington generally requires consent before recording private conversations. Keep the camera visible, include the notice in your form, and avoid recording private audio conversations without consent.
